# Install TheIsleMinimap and find your first position

[Back to the project overview](../README.md)

## Before you start

- **Windows 11 & Windows 10 (64-bit)**.
- The Isle: EVRIMA’s **Gateway** map.
- A TheIsleMinimap license and an internet connection for activation and periodic license checks.

Create your account on the [website](https://theisleminimap.com/account/?action=signup). You can purchase access or accept a shared-license invitation from a friend.

## Download and activate

1. Sign into your account and open **Download**.
2. Download the Windows setup from that page and run it.
3. Follow the installation prompts, then launch TheIsleMinimap.
4. Reveal your key in **Account Portal > Licenses**, then enter it in the app.

The Download page includes illustrated explanations of Windows installation prompts. Check those instructions if a prompt appears, and use the setup provided by the official website.

## Follow Get started

The first-run assistant helps you choose app size, opacity, mouse interaction, an Earplugs shortcut and a position-update method. You can reopen it from **Settings > Position Updates > Get started**.

For key-triggered reading, open The Isle’s Asset Location panel with Tab. If you changed that game key, select the matching key in the app. For automatic reading, keep the coordinate panel visible. Clipboard updates are available if you prefer copying coordinates yourself.

Follow [the position-update guide](position-updates.md) to set a reading area and capture your first location.

## Play alone or with friends

Solo players can choose a marker color and enable up to three personal map pins in **Solo Settings**. Squad players can create or join a private squad in **Squad Settings** to share positions and a destination pin.
